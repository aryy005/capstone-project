AEGIS — Top 15 Expected Viva Questions & Expert Answers

Quick-reference guide for Capstone Evaluators & Examiners
Q1 • System Concept
Q1: What is the main objective of the AEGIS project?
Answer: AEGIS is an AI-powered emergency command center platform designed to reduce emergency response latency by combining 6 client-side AI algorithms (Bayesian inference, A* routing, K-Means clustering, Decision Tree triage, Monte Carlo simulation, and Neural Network damage prediction) to triage incidents, compute evacuation routes, allocate rescue fleets, and export OASIS CAP alerts.
Q2 • AI Algorithms
Q2: How does the A* Pathfinding algorithm avoid hazard zones?
Answer: The A* router evaluates cost f(n) = g(n) + h(n) on a 50×50 spatial grid, applying a dynamic hazard penalty function W(e) = Dist(e) × (1 + 1000 × Risk(e)). When an edge intersects a flood or chemical hazard zone, its cost increases 1,000-fold, forcing the algorithm to find a safe alternative route.
Q3 • AI Algorithms
Q3: Why did you use K-Means++ clustering for staging hubs?
Answer: Standard K-Means can get stuck in poor local minima depending on initial centroid choices. K-Means++ seeds initial centroids proportional to squared distance, ensuring optimal spatial positioning of relief camps relative to emergency incident clusters using Haversine spherical distance.
Q4 • System Architecture
Q4: Why is the platform built using Vanilla JS without heavy frameworks like React?
Answer: Vanilla JavaScript ensures ultra-fast boot times, zero framework bundle overhead, 60 FPS GIS rendering performance, and zero-dependency offline PWA execution on low-spec emergency response hardware and mobile devices.
Q5 • Real Data
Q5: Is the weather data real or hardcoded?
Answer: The weather data is live and real, fetched asynchronously from the Open-Meteo REST API for scenario GPS coordinates (e.g. Chennai, Uttarakhand, Assam). The incident updates run on a real-time stochastic simulation engine for demonstration safety.
Q6 • Industry Standards
Q6: What is OASIS CAP v1.2 and why did you implement it?
Answer: OASIS Common Alerting Protocol (CAP v1.2) is the international standard format for emergency alerts used by the National Disaster Management Authority (NDMA) and NDRF. AEGIS exports standardized CAP JSON/XML payloads so dispatches can interface with official national alerting infrastructure.
Q7 • Mobile Support
Q7: How does AEGIS work on mobile devices for field responders?
Answer: AEGIS is structured as an installable Progressive Web App (PWA) with manifest.json and a background service-worker.js that caches core app shell assets for offline execution on responder smartphones.
Q8 • Machine Learning
Q8: How does the 6th AI module (Neural Network) work?
Answer: The Neural Network is a 2-layer feed-forward model with Sigmoid activation. It takes incident magnitude, wind speed, affected population, and infrastructure vulnerability as inputs to compute non-linear casualty estimates and economic loss projections.
Q9 • Future Scope
Q9: What is your plan for Phase 2 development?
Answer: Phase 2 includes YOLOv8 computer vision for aerial drone feed damage analysis, Whisper NLP for regional Indian language 112 emergency calls, direct NDMA Sachet API synchronization, and offline Bluetooth LE mesh networking.
Q10 • GIS Mapping
Q10: How does the 3D GIS Visualization work?
Answer: The GIS Command map features dual visualization modes: a 2D Leaflet spatial map and a 3D Tactical Perspective matrix transformation engine (`rotateX 52°`) that elevates incident pins with 3D drop-shadows and terrain drone perspective.
